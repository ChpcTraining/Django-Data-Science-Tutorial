# Django for Data Science

## From Your First Django Website to a CSV Data Viewer & Plotter

Learn how to build data-driven web applications using **Django, Pandas and Matplotlib**.

This tutorial starts with your first Django webpage and progressively builds toward a complete **CSV Data Viewer & Plotter**.

## Final Project

By the end of the course you will build a Django web application that can:

- Upload CSV datasets
- Explore rows and columns
- Preview data
- Generate descriptive statistics
- Select columns
- Generate plots
- Provide analysis through a simple JSON API
